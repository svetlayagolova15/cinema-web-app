# Онлайн-кинотеатр «КиноМир»

Веб-приложение для просмотра каталога фильмов и бронирования билетов.

## Функционал:
- Регистрация и авторизация пользователей.
- Просмотр каталога фильмов и сеансов.
- Оформление заявки на покупку билетов (выбор количества, способа оплаты).
- Личный кабинет пользователя с историей заявок.
- Панель администратора для управления статусами заявок.

## Технологии:
- Frontend: HTML5, CSS3 (Flexbox, Grid), JavaScript.
- Backend: Python (Flask), REST API.
- База данных: MySQL.
